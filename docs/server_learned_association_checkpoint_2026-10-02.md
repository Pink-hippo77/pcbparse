# 服务器 OCR 角色与归属学习验证（2026-10-02）

私有候选已完成训练、30 图完整下游流水线对照及来源核验。五项精确字段命中均未退化，四项 raw-v1 代理指标改善或持平。四项官方 F1 均 ≥95% 的目标尚未达到，官方评测器尚未获得；本实验不能宣称竞赛精度或生产就绪。

## 数据、模型与门槛

全部运算与报告生成在 10.128.64.7 的 `/home/data/yinjx/pcbparse-competition/project` 完成。只读取 dataset300-v2 的 240 张训练图标注；按重复组确定 214 图拟合、26 图内部验证，未读取外部 30 图验证或 test GT 进行训练与门槛选择。两种模型分别预测文本到器件或引脚的角色和归属。使用可见字符串形态、字符特征、相对几何及方向；不记忆器件身份，不生成编号。仅唯一、raw-v1 可评估的标注文本作为监督，未标注文本不伪造负标签。

训练约 87.03 秒，GPU1 上顺序完成；每个模型执行 52 轮，最优第 32 轮。两份必要权重共 47,362 字节，未保存重复轮次权重。内部校准按 >=98% 归属及角色精度、至少 20 个接受样本、间隔 >=0.2 选择门槛；这是已标注目标和标注几何下的条件诊断，不能等同真实 OCR 部署精度。数据构建在候选遗漏真实对象时加入该对象，相关次数及覆盖率保存在 lineage.json，后续校准需进一步验证不扩展候选池的真实覆盖。IC 型号没有达标门槛，保持关闭。
