## 服务器资源与并行收益

104 个逻辑 CPU、503 GiB RAM、两张 RTX A6000 48GB。GPU0 已由其他任务占用，未触碰；GPU1 用于当前实验。共享主机负载约 160–170，因此采用低优先级进程和线程上限。

同配置、同输入 30 张加 2 张烟雾测试：4 路 613.0s，8 路 484.0s，耗时缩短 21.05%；30 张官方 JSON 与 4 路版本字节一致，重复的 2 张也一致。8 路峰值显存 32251 MiB，最慢单图 351.5s，低于 600s；全批低于 7200s。共享负载及缓存会影响时延，此处是实际实验比较。

每个推理进程 2 个 CPU 线程，8 路最多 16 个。训练保持单 GPU 串行；离线 CPU 评估、数据审计并行。所有 GPU 实验共用排他 lease，切换时校验 UUID、显存/利用率/实际 GPU PID。没有同时启动两项训练。

最慢图片的引脚推理约 1 秒，主要耗时是 OCR 和导线处理。增加模型规模不能解决这些阶段的全部开销，后续应复用不变的模型输出并将 GPU 感知与 CPU 图构建分阶段调度。

## 主要瓶颈及已经完成的修正

1. **语义字段缺失导致候选大量丢失。** 感知阶段匹配 1549 个真实引脚，最终仅保留 539 个；最终删除 793 个器件、1749 个引脚，其中 682 个缺编号、1067 个失去有效器件归属。3260 个真实连接对中只有 184 对同时保留两端，连接召回上限为 5.64%。应优先改善可见器件标识、引脚编号及其归属，再优化连接；禁止伪造编号或放宽 Validator。
2. **训练/验证数值和坐标契约问题。** 私有实验已修正 FP16 focal 非有限值、连续高斯缺少单位正样本、验证损失与训练配置不一致，以及相同输入尺寸时缺失 box_rects 的验证路径；有限梯度、目标/坐标不变和盒先验均有独立证据。cycle46 原始“boundary”模式实际上没有盒先验，cycle51 已真实重跑并补充解释，原始报告保留。
3. **预算单位错误。** native PinAdapter 用热图坐标计算声称以推理画布像素定义的 edge_length_v1 预算。stride4 的例子给出 12 个槽，按文档单位应为 30 个；旧 30 张中有元数据的 1169 个器件里，1168 个受到单位差异影响。这是预算容量审计，不能直接等同于真实漏检数。生产源尚未修改；需单独的修复及真实图对照。
4. **不能靠扩大编号正则解决语义。** 允许可见 EP/长数字后，新增 5 个长数字编号决策，正确编号未增加，网络 FP 348→354。该方案排除，原有数值置信门槛保持。
5. **继续训练产生过拟合。** 校准后的续训最佳召回 64.85%，未达到原有 65% 子模型门槛；未降低门槛，未晋级。被淘汰的 cycle39、cycle54 共 8 个正式权重已清理 174.89 MiB；报告、日志、预测和清理哈希保留。当前候选及生产模型保留，无新下载/副本。

## 大参数模型与下一步验证

在相同 GT 器件 ROI 的离线比较中，Pin32 按原图 5px 计算的最好定位 F1 为 74.85%，精确率 85.95%、召回率 66.29%，阈值 0.125。旧 Pin16 的最佳同类定位 F1 为 69.11%。这是组合优化和阈值校准结果，不能当作官方 PinF1。

校准后的 ROI4 指标满足该实验原有子模型门槛：F1 ≥0.70、精确率 ≥0.80、召回率 ≥0.65、预测/GT 比例在 [0.65,1.20]。这不改变原始训练报告 gate_failed 状态，不代表 95% 验收或生产就绪。

cycle64 已完成 30 张新鲜四模型推理（8 路，450.7s，最慢单图321.7s，峰值32009MiB），32次严格序列化和2张重复输入均通过。阈值0.125的完整输出：引脚点F1 31.67%，连接对F1 3.53%；相对0.1分别下降0.18和0.22个百分点，正确引脚编号少2个。该阈值试验排除，当前优先保留0.1。

cycle66 正保持与cycle64相同的权重/阈值0.125/固定预算，仅将先验改为 filled_rect_v1 + margin16；它已在cycle64结束后取得GPU lease并进入8路完整推理。使用0.125是为了与cycle64隔离比较先验，并非已选定最终阈值。两者都有独立CPU离线评估，推理进程不可访问GT。不能用ROI指标代替完整流水线效果。

后续顺序：完成先验对照 → 私有验证预算单位修复 → 用训练集的真实检测/OCR/引脚候选训练字段归属与互斥角色 → 改进导线误检和连通性。新训练继续只用 dataset300-v2 的 grouped 240/30/30，验证/测试仅作开发回归。
