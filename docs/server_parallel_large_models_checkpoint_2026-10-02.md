## 绑定瓶颈与后续实验

离线 GT 文本框附近的精确 token 可用性诊断：YOLO26l 标号 359/364、引脚名 551/611，但最终分别命中 211、171，提示角色和对象归属损失。引脚号附近仅有 413/650 个精确 token，仍需小字识别优化。这是离线定位诊断，不是 OCR 准确率或性能上限。

下一轮仅在 240 训练图学习 OCR 角色与归属，利用几何、边界方向和文本特征构建配对并消解冲突。只复制真实可见文本并保留证据；不得自动编号、补 key 或读取同名 GT。分别报告各字段、失败样本、各分项和时延，不以加权代理成绩替代四项 ≥95% 的目标。
