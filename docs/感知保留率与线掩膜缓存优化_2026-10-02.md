# 感知保留率与线掩膜缓存优化

本轮确认：当前端到端损失主要来自感知对象在语义绑定与严格输出过程中被删除，而不仅是检测模型容量不足。另完成 30 张服务器真实掩膜的内容一致性验证，并实现了进一步减少标签图重复扫描的实验缓存。YOLO11l 已训练完成，YOLO26l 在最新证据快照完成 80 轮、仍在训练；更大 YOLO 的完整原图比较尚未开始。

生产模型锁、配置和服务器活跃源码保持不变。本轮未晋级模型。器件、引脚、网络、线段四项均 ≥95% 的目标仍未满足，官方四项指标仍为 null。

## 1. 感知结果到最终输出的损失

复用已经闭合的 image-only PP-OCRv6 medium 感知产物和周期 15 的字段分类候选最终产物，使用 `pcbparse.evaluation.raw_cli` 对同一批 30 张原图做离线 raw-v1 对照。GT 仅由离线评估器访问，没有新模型推理、标签回填或预测改写。感知阶段尚无最终语义和电气网络，因此这里只比较器件框、引脚点；这些都是开发代理指标，不是官方竞赛指标。

| 指标 | 感知阶段 | 最终输出 |
|---|---:|---:|
| 器件框 TP / FP / FN | 913 / 240 / 199 | 338 / 31 / 774 |
| 器件框 Precision | 79.18% | 91.60% |
| 器件框 Recall | 82.10% | 30.40% |
| 器件框 F1 | 80.62% | 45.64% |
| 引脚点 TP / FP / FN | 1610 / 1198 / 1030 | 458 / 164 / 2182 |
| 引脚点 Recall | 60.98% | 17.35% |
| 引脚点 F1 | 59.10% | 28.08% |

按相同内部 ID 核对，1,153 个感知器件最终保留 369 个，删除 784 个；2,808 个感知引脚最终保留 622 个，删除 2,186 个。没有新增对象，所有保留器件框和引脚点均未改变。删除数量与流水线实际裁剪记录一致，不依赖 GT 匹配结果来猜测 owner 是否丢失。

删除的 784 个器件都缺少可输出的 key。引脚中 708 个因缺少引脚号被删除，1,478 个因缺少可保留的所属器件被删除。后者包括器件已经被删除的影响，不能全部解释为引脚 detector 漏检。30 张最终输出仍全部是 `degraded_nonempty`。

这说明更大 YOLO 即使提高框召回，也需要 OCR 位号识别、器件语义绑定、引脚号及所属关系一起改善，才能留到最终 JSON。严格 Validator 和缺失字段门禁应保留，不能通过自动编号或占位字符串获得表面召回。

对既有验证数据额外检查了 128 个器件的输出上限：这批图最多 115 个可评估器件，没有任何图超过上限。因此它当前没有造成理论召回上限；不应无证据地先扩大候选上限。这一结论只适用于该开发批次。

## 2. 已完成的服务器 30 张真实掩膜对照

服务器在 CPU 上使用当前锁中的 wire 模型生成每张图的真实掩膜，原始与周期 12 的点对搜索候选共享完全相同的掩膜。对照覆盖完整线段、交点、坐标恢复、去重及修复元数据；30/30 内容逐字节相同，输入掩膜未变，访问审计没有标签/sidecar 访问，运行源码、模型和配置哈希未变。

30 张的 CPU 向量化耗时合计从 2,058.72 秒降至 1,517.12 秒，减少约 26.3%。这个批量结果小于此前单图 0030 的 7.3 倍提速，不能将单图比例推广到全部图。0092 为 318.63→80.67 秒，而 0165 为 165.04→165.22 秒、0190 为 92.41→93.08 秒，均显示其他热点仍然存在。

这不是四模型 GPU 整图时延，也不是 GPU P95 或官方预算证明。完整配对验证进程耗时约 3,731 秒，包括 CPU 分割与两次向量化。

## 3. 找到重复扫描热点并实现缓存候选

对本地 0165 的真实模型掩膜剖析，启用周期 12 点对搜索后仍调用了 11,242 次最近像素对函数，25,141 次 `argwhere`。重复扫描标签图的 `nonzero` 在一次带 cProfile 的 CPU 向量化中占约 45.7 秒，成为主要热点。函数去重的剖析只占约 3.7 秒，暂不将它作为本轮主要改动。

新实验候选仅在一次掩膜闭合调用中缓存正标签的行优先像素列表、必要的右侧像素集合和半径偏移。桥接新增像素计数在相同欧氏距离范围内检查局部整数方格，仍使用原有 `hypot` 判断。缓存随该掩膜调用结束释放，不跨图复用；不改变闭合半径、距离、平局顺序、虚拟修复标志或记录字段。

5 项定向 unittest 通过，覆盖像素顺序、空/满图、边界、桥接、随机掩膜、等距选取、缺失组件与大半径回退。另一个空间去重实验的 6 项测试通过，但它没有加入缓存候选，也没有部署。

| 本地同一真实掩膜完整向量化 | 对照 | 缓存候选 | 内容 |
|---|---:|---:|---|
| 0165 | 80.58 秒 | 22.75 秒 | 1,838 线段、1,743 交点及完整修复元数据字节相同 |
| 0030 | 2.61 秒 | 2.09 秒 | 596 线段、599 交点及完整修复元数据字节相同 |

上述时间包含 cProfile 开销，来自本机 CPU，不能作为服务器 GPU 的时延结论。两个实际掩膜比较均为输入不变、GT 访问为 0、生产源码未变。失败的本地 CUDA 隐藏检查和诊断元数据编码日志保留，修复后重新运行；没有删减元数据来取得一致性。
